## Данные и результат

Источник данных — [FlightPrices на Kaggle](https://www.kaggle.com/datasets/dilwong/flightprices). Использован CSV-фрагмент `itineraries_apr16_may17.csv` объёмом 4,45 ГиБ (12 857 310 строк). На учебном кластере он находится в HDFS по адресу `/user/user0/datasets/itineraries_apr16_may17.csv`. Файл CSV не помещён в GitHub из-за размера; репозиторий содержит код и сохранённые результаты анализа.

Проверены типы признаков и пропуски, рассчитаны описательные статистики и 99,5-й процентиль, обработаны крайние значения, построены распределения и матрица корреляций. В итоговом наборе 12 725 169 строк. Он сохранён в таблицу Iceberg `statskevich_database.sobd_lab1_flight_prices_processed_table`; существующая база данных сохранена.

## Как показать выполнение

1. На удалённом сервере `hadoop-node` открыть ноутбук в VS Code.
2. Выбрать ядро `pyspark-env` (Python 3.11.9). Использован Spark 3.5.2 с мастер-режимом YARN.
3. Показать сохранённые выводы ячеек: размер и схему исходного CSV, пропуски, статистики до и после обработки, графики, корреляции и проверку таблицы Iceberg.
4. Для повторного запуска нужен доступ к указанному файлу в HDFS и существующей базе `statskevich_database`. Ячейки выполняются последовательно сверху вниз. Запись таблицы устроена так, чтобы при повторном запуске уже существующая таблица проверялась без перезаписи.

Исходный CSV и общие ресурсы кластера в репозитории не публикуются.
